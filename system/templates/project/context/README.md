# Контекст проекта

Общее знание о продукте и аудитории для всех страниц этого проекта: что за продукт, для кого, какими словами говорим, что мешает людям сказать «да». Агент читает этот файл **первым**, когда получает задачу по проекту, и затем открывает только нужные файлы. Материалы одной страницы лежат отдельно, в `content/<страница>/`.

## Состав

| Файл | Что внутри | Статус | Обновлено | Источники |
|---|---|---|---|---|
| `product.md` | Продукт, оффер, тарифы, первоисточники условий | пусто | | |
| `segments.md` | Сегменты и их JTBD: задача, боль, триггер, язык | пусто | | |
| `voice.md` | Тон, «ты» / «вы», словарь, запрещённые слова | пусто | | |
| `objections.md` | Банк возражений: цитата, источник, частота, сегмент | пусто | | |
| `facts.md` | Проверенные факты уровня продукта: цифры, кейсы, отзывы | пусто | | |
| `competitors.md` | Конкуренты и наше отличие с цифрами | пусто | | |
| `sources/` | Сырые материалы: кастдевы, выгрузки, документы | — | | |

Состав можно расширять: если знанию нужен отдельный файл (Jobs to be Done, стадии готовности, путь клиента, глоссарий, юридические рамки, второй продукт), он добавляется в эту папку и строкой в таблицу выше.

Статусы: **пусто** — файл ещё не заполнен, его как будто нет · **черновик** — заполнен частично или не проверен владельцем · **актуально** — проверено владельцем, дата в «Обновлено».

## Правила

- **Сырьё и выжимки раздельно.** Исходные материалы кладутся в `sources/` и не правятся. Файлы этой папки — выжимки; у каждого утверждения ссылка на источник: `sources/<файл>`, документ и пункт или URL с датой.
- **Пишет владелец.** Агент дополняет и меняет контекст только с согласия пользователя в чате и сообщает, что именно изменил. Найденное по ходу работы над страницей (новое возражение, новый факт) агент предлагает добавить сюда, а не записывает молча.
- **Дата и противоречия.** После правки обновляется «Обновлено» в таблице выше. Если первоисточник новее выжимки или страница расходится с контекстом, агент говорит об этом пользователю и не сглаживает расхождение.
- **Персональные данные.** В выжимках — роли, а не имена: «владелец студии, 2 сотрудника». Имена, телефоны и почты остаются только в `sources/`, если без них нельзя.
- **Только этот проект.** Контекст другого проекта не читается и не копируется.
