# Сегменты и JTBD

Статус: пусто · Обновлено: — · Источники: —

Сегмент — это задача, а не демография: что человек пытается сделать, а не сколько ему лет. Формулировки — словами самих людей из `sources/`.

## Сегмент: <название> 🔴/🟡/🟢

| | |
|---|---|
| **Кто** | Роль и ситуация, без имён |
| **Задача (JTBD)** | «Когда …, я хочу …, чтобы …» |
| **Боль** | Что мешает сейчас |
| **Триггер** | Когда начинает искать решение |
| **Чем пользуется сейчас** | Текущее решение или обходной путь |
| **Как говорит** | Слова и фразы сегмента (цитаты со ссылкой) |
| **Что важно при выборе** | |
| **Как приходит** | Каналы |
| **Источники** | `sources/…` |
