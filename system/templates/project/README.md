# Project workspace

This project owns its namespace, design values, classes, components, pages, results and Taptop import evidence. Read `AGENTS.md` and `taptop.project.json` before changing it. Commands run from the Bridge folder: `npm run toolkit -- <command> --project projects/<this-folder>`.

- `context/` — what the project knows about its product and audience, shared by every page: product and offer, segments and JTBD, voice, objections, facts, competitors; raw custdev notes, exports and documents in `context/sources/`. Written by the owner; agents read `context/README.md` first and change the folder only with the owner's consent.
- `input/` — original material and source evidence (`input/<name>/index.html`, its CSS and images, intake files). Never rewritten.
- `design-system/` — this project's values: `foundations.json`, `registry.json`, `sources.md` (where every value came from, what is MISSING), and once there is evidence `kit.json` and `roles.css`. Starts empty.
- `source/artifacts.json` — the UI kit, components and pages this project builds. Register entries with `artifact add`.
- `source/ui-kit/` — generated by `ui-kit` from `design-system/kit.json`; do not edit by hand. `source/components/`, `source/pages/` — HTML/CSS written for this project.
- `output/html/index.html` — results page; `output/html/<artifact>--<build>/` previews and `output/json/<artifact>--<build>.json` import packages with the same build ID.
- `.taptop/` — private state: results catalogue, build journals, history, lock. Never publish it.

`npm run toolkit -- doctor --project projects/<this-folder>` shows the state and the next step. Do not copy another project's namespace, `.taptop/` or receipts into this one.
